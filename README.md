# 🚦 Smart City Traffic Forecasting

A machine learning-based system for analyzing and forecasting traffic patterns across four city junctions. The project identifies peak hours, busy junctions, and traffic variations across working days, weekends, and holidays.

## 🔍 Features

- Data cleaning and preprocessing
- Time-based feature engineering
- Holiday and working-day analysis
- Traffic pattern visualization
- Peak-hour detection
- Multiple ML model comparison
- Traffic forecasting using Gradient Boosting
- Interactive Streamlit dashboard

## 🤖 Machine Learning

Models evaluated:
- Linear Regression
- Decision Tree
- Random Forest
- Gradient Boosting

**Best Model:** Gradient Boosting  
**R² Score:** 0.9691

## 🛠️ Tech Stack

Python • Pandas • NumPy • Scikit-learn • Matplotlib • Seaborn • Streamlit • Joblib

## 🎯 Goal

To provide data-driven traffic insights that can support traffic management and future smart-city infrastructure planning.
